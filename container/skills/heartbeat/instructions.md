## 3-Minute Progress Updates

When working on ANY task that takes more than 3 minutes, you MUST send a progress update every 3 minutes using `mcp__nanoclaw__send_message`. Do not wait for a reminder.

Your update must include:
- What you just completed
- What you are currently doing
- What remains

This applies to all work: code editing, file reading, process management, git operations, research — everything. If you are unsure whether 3 minutes have passed, send the update anyway.
